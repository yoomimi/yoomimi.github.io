# 방명록 설정 방법

방명록 글은 구글 시트에 저장되고, 시트에 붙인 Apps Script 웹앱이 사이트와 시트 사이를 이어 줍니다.
아래 순서대로 한 번만 설정하면 됩니다. 10분 정도 걸립니다.

## 1. 구글 시트 만들기

1. https://sheets.google.com 에서 새 스프레드시트를 만듭니다. 이름은 아무거나 (예: `guestbook`).
2. 첫 번째 탭을 비워 둡니다. 헤더 행도 필요 없습니다. 스크립트가 A~F열에 직접 씁니다.
   - A: id, B: 시간, C: 이름, D: 메시지, E: 내 답글, F: 숨김 표시

## 2. Apps Script 붙이기

1. 시트 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.
2. 편집기에 기본으로 들어 있는 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣습니다.
3. 저장(Ctrl+S)합니다.

## 3. 주인 키 설정

답글 달기와 삭제는 이 키를 아는 사람만 할 수 있습니다.

1. Apps Script 왼쪽 메뉴에서 **프로젝트 설정(톱니바퀴)**을 엽니다.
2. 아래쪽 **스크립트 속성 > 스크립트 속성 추가**를 누릅니다.
3. 속성 이름에 `OWNER_KEY`, 값에 원하는 비밀번호를 넣고 저장합니다.

## 4. 웹앱으로 배포

1. 오른쪽 위 **배포 > 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형을 **웹 앱**으로 고릅니다.
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누릅니다. 처음에는 권한 승인 창이 뜹니다. "고급 > (프로젝트 이름)(으)로 이동"을 눌러 허용합니다.
5. 배포가 끝나면 `https://script.google.com/macros/s/…/exec` 형태의 **웹 앱 URL**이 나옵니다. 복사합니다.

## 5. 사이트에 URL 넣기

`index.html`에서 아래 줄을 찾아 따옴표 안에 방금 복사한 URL을 넣고 커밋, 푸시합니다.

```js
var GUESTBOOK_URL = '';  // paste the Apps Script web app URL (…/exec) here
```

URL이 비어 있는 동안에는 방명록 섹션이 사이트에 보이지 않습니다.

## 사용법

- 방문자는 이름(선택)과 100자 이내 메시지를 남길 수 있습니다. 링크는 막혀 있고, 같은 브라우저에서는 10분에 한 번만 쓸 수 있습니다.
- 사이트에 최신 10개만 보입니다. 전체 목록은 시트에서 볼 수 있습니다.
- **답글과 삭제**: 주소 끝에 `#admin`을 붙여 접속하면 (예: `https://yoomimi.github.io/#admin`) 주인 키를 묻습니다. 입력하면 각 글 옆에 Reply, Delete 버튼이 생깁니다. 삭제한 글은 시트에서 지워지지 않고 F열에 `x`가 표시되어 사이트에서만 숨겨집니다.
- 키를 5번 틀리면 1시간 동안 주인 기능이 잠깁니다.

## 코드를 고쳤을 때

`Code.gs`를 수정한 뒤에는 **배포 > 배포 관리 > 연필 아이콘 > 버전: 새 버전 > 배포**를 해야 반영됩니다. URL은 그대로입니다.
