# 방명록 설정 방법

방명록 글은 구글 시트에 저장되고, 시트에 붙인 Apps Script 웹앱이 사이트와 시트 사이를 이어 줍니다.
아래 순서대로 한 번만 설정하면 됩니다. 10분 정도 걸립니다.

## 1. 구글 시트 만들기

1. https://sheets.google.com 에서 새 스프레드시트를 만듭니다. 이름은 아무거나 (예: `guestbook`).
2. 첫 번째 탭을 비워 둡니다. 헤더 행도 필요 없습니다. 스크립트가 A~F열에 직접 씁니다.
   - A: id, B: 시간, C: 이름, D: 메시지, E: 내 답글, F: 숨김 표시

## 2. Apps Script 붙이기

1. 시트 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.
2. 편집기에 기본으로 들어 있는 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣습니다.
3. 저장(Ctrl+S)합니다.

## 3. 주인 키 설정

답글 달기와 삭제는 이 키를 아는 사람만 할 수 있습니다.

1. Apps Script 왼쪽 메뉴에서 **프로젝트 설정(톱니바퀴)**을 엽니다.
2. 아래쪽 **스크립트 속성 > 스크립트 속성 추가**를 누릅니다.
3. 속성 이름에 `OWNER_KEY`, 값에 원하는 비밀번호를 넣고 저장합니다.

## 4. 웹앱으로 배포

1. 오른쪽 위 **배포 > 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형을 **웹 앱**으로 고릅니다.
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누릅니다. 처음에는 권한 승인 창이 뜹니다. "고급 > (프로젝트 이름)(으)로 이동"을 눌러 허용합니다.
5. 배포가 끝나면 `https://script.google.com/macros/s/…/exec` 형태의 **웹 앱 URL**이 나옵니다. 복사합니다.

## 5. 사이트에 URL 넣기

`index.html`에서 아래 줄을 찾아 따옴표 안에 방금 복사한 URL을 넣고 커밋, 푸시합니다.

```js
var GUESTBOOK_URL = '';  // paste the Apps Script web app URL (…/exec) here
```

URL이 비어 있는 동안에는 방명록 섹션이 사이트에 보이지 않습니다.

## 사용법

- 방문자는 이름(선택)과 100자 이내 메시지를 남길 수 있습니다. 링크는 막혀 있고, 같은 브라우저에서는 10분에 한 번만 쓸 수 있습니다.
- 사이트에 최신 10개만 보입니다. 전체 목록은 시트에서 볼 수 있습니다.
- **답글과 삭제**: 주소 끝에 `#admin`을 붙여 접속하면 (예: `https://yoomimi.github.io/#admin`) 주인 키를 묻습니다. 입력하면 각 글 옆에 Reply, Delete 버튼이 생깁니다. 삭제한 글은 시트에서 지워지지 않고 F열에 `x`가 표시되어 사이트에서만 숨겨집니다.
- 키를 5번 틀리면 1시간 동안 주인 기능이 잠깁니다.

## 새 글 메일 알림

누군가 글을 남기면 시트에 저장되는 동시에 메일이 옵니다. 기본으로는 Apps Script를 만든 계정(웹앱을 "나"로 실행하는 그 계정)으로 갑니다.

- 다른 주소로 받고 싶으면 스크립트 속성에 `NOTIFY_EMAIL`을 추가하고 값에 주소를 넣습니다.
- 메일 제목은 `[Guestbook] 이름: 메시지 앞부분`이고, 본문에 전체 메시지, 시간, 시트 링크, 관리 링크가 들어 있습니다.
- Apps Script 메일 발송은 하루 100통(무료 계정 기준) 한도가 있습니다. 방명록 용도로는 충분합니다.
- 이미 배포한 뒤에 이 기능을 추가했다면, 아래 "코드를 고쳤을 때" 순서대로 새 버전을 배포해야 합니다.
- **메일 권한을 한 번 승인해야 합니다.** "배포 관리"에서 새 버전만 올리면 권한 창이 뜨지 않을 수 있습니다. 그러면 글은 저장되는데 메일만 조용히 실패합니다. 편집기에서 함수 선택 상자를 `testNotify`로 바꾸고 **실행**을 누르세요. 권한 승인 창이 뜨면 "고급 > (프로젝트 이름)(으)로 이동 > 허용"을 누릅니다. 테스트 메일이 오면 끝입니다.
- 그래도 안 오면: 스팸함을 확인하고, 왼쪽 메뉴 **실행(Executions)**에서 `doPost` 항목을 열어 `notify_ failed` 로그가 있는지 봅니다.

## 코드를 고쳤을 때

`Code.gs`를 수정한 뒤에는 **배포 > 배포 관리 > 연필 아이콘 > 버전: 새 버전 > 배포**를 해야 반영됩니다. URL은 그대로입니다.

코드를 바꾸면 필요한 권한이 달라질 수 있습니다. 권한이 모자라면 페이지에 "couldn't load"가 뜨거나 메일만 안 옵니다. 그럴 때는:

1. 편집기에서 함수 선택 상자를 `setup`으로 바꾸고 **실행**을 누릅니다. 이 함수는 시트·메일·계정 정보를 한 번씩 건드리므로 필요한 권한을 한 번에 다 요청합니다.
2. 권한 창에서 "고급 > (프로젝트 이름)(으)로 이동 > 허용"을 누릅니다. 허용 화면에 **스프레드시트**와 **이메일 전송** 항목이 둘 다 보여야 합니다.
3. 실행 로그에 `Sheet OK`, `Mail OK`가 찍히면 됩니다. 이어서 새 버전을 배포합니다.

권한이 빠지는 일을 아예 막으려면 `appsscript.json`을 같이 올려 두는 것이 좋습니다. 편집기 **프로젝트 설정(톱니바퀴) > "appsscript.json" 매니페스트 파일을 편집기에 표시**를 켠 뒤, 왼쪽 파일 목록에 나타난 `appsscript.json`의 내용을 이 폴더의 `appsscript.json`으로 바꿉니다. 그러면 어떤 함수를 실행하든 권한 창이 항상 세 가지 권한을 모두 요청합니다.

## 뭔가 안 될 때 직접 확인하기

웹앱 URL을 브라우저 주소창에 그대로 열어 보세요. 정상이면 `[...]` 형태의 JSON이 보이고, 권한 문제면 "Exception: ... 권한이 없습니다" 같은 오류 문장이 보입니다. 그 문장에 어떤 권한이 빠졌는지 적혀 있습니다.
